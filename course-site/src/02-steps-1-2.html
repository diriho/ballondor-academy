Git vs GitHubGit ou GitHub ?

Git is a program on your computer that records snapshots (called commits) of your project, so you can always go back. GitHub is a website that stores a copy of your repository online, so you can share it, work from another computer and show it to others.

Git est un programme sur ton ordinateur qui enregistre des instantanés (des commits) de ton projet pour pouvoir toujours revenir en arrière. GitHub est un site qui stocke une copie de ton dépôt en ligne pour le partager, travailler depuis un autre ordinateur et le montrer.
