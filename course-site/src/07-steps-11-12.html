How the translation worksComment fonctionne la traduction

Il y a deux sortes de textes. Le texte d'interface (boutons, libellés) vit dans un dictionnaire dans app.js. Le texte des données (descriptions, pays) vit dans la base, en paires de colonnes : description_en/description_fr, nationality/nationality_fr.

  4. TEXT.en.mostWins et TEXT.fr.mostWins contiennent les deux versions ; t('mostWins') renvoie celle de la langue courante. Certaines entrées sont des fonctions, pour les pluriels : t('found', 3).

  6. applyLanguage() parcourt chaque élément [data-i18n], reconstruit les selects et réaffiche les cartes. Le choix est mémorisé dans localStorage.
