HTML, CSS, JS: three jobsHTML, CSS, JS : trois rôles

HTML says what things are (a title, a button, a list). CSS says how they look. JavaScript says what they do. Today is pure structure, so the page will look plain. That's expected.

Le HTML dit ce que sont les choses (un titre, un bouton, une liste). Le CSS dit à quoi elles ressemblent. Le JavaScript dit ce qu'elles font. Aujourd'hui c'est de la structure pure : la page sera brute, c'est normal.

How CSS worksComment fonctionne le CSS

A CSS file is a list of rules. Each rule picks elements with a selector, then sets properties:

Un fichier CSS est une liste de règles. Chaque règle choisit des éléments avec un sélecteur, puis définit des propriétés :

SelectorSélecteurPicksSélectionne
h1every <h1>tous les <h1>
.cardevery element with class="card"tout élément avec class="card"
#searchthe one element with id="search"l'unique élément avec id="search"
.card imgimages inside a cardles images dans une carte
button[aria-pressed='true']buttons whose attribute has that valueles boutons dont l'attribut a cette valeur
.card:hovera card while the mouse is over itune carte survolée par la souris

When two rules disagree, the more specific selector wins (#id beats .class beats tag), and if they're equal, the one written last wins. That's the “cascade” in Cascading Style Sheets.

Quand deux règles se contredisent, le sélecteur le plus spécifique gagne (#id bat .classe qui bat balise) ; à égalité, la règle écrite en dernier gagne. C'est la « cascade » de Cascading Style Sheets.

Variables, units, fontsVariables, unités, polices

  • Custom properties such as --gold: #e6b94d; are CSS variables. Define the colours once, use var(--gold) everywhere, change the whole theme in one line.
  • Les propriétés personnalisées comme --gold: #e6b94d; sont des variables CSS. Définis les couleurs une fois, utilise var(--gold) partout, change tout le thème en une ligne.
  • Units: px fixed, rem relative to the base font size (1rem ≈ 16px), % of the parent, vw % of the screen width. clamp(3rem, 8vw, 6rem) means “8% of the screen, but never below 3rem or above 6rem”.
  • Unités : px fixe, rem relatif à la taille de police de base (1rem ≈ 16px), % du parent, vw % de la largeur d'écran. clamp(3rem, 8vw, 6rem) veut dire « 8 % de l'écran, jamais moins de 3rem ni plus de 6rem ».
  • Fonts come from Google Fonts: Bebas Neue (tall, sporty headings) and Inter (readable text).
  • Les polices viennent de Google Fonts : Bebas Neue (titres hauts et sportifs) et Inter (texte lisible).
