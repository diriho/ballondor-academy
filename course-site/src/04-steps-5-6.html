Grid

Grid works in two dimensions: you declare columns (and rows) and children drop into them. grid-template-columns: 270px 1fr means “a 270px sidebar, then all the remaining space” (fr = fraction of free space). For the cards, repeat(auto-fill, minmax(220px, 1fr)) means “as many 220px+ columns as fit”: responsive without any media query.

Grid travaille en deux dimensions : tu déclares des colonnes (et des lignes) et les enfants s'y placent. grid-template-columns: 270px 1fr signifie « une barre latérale de 270px, puis tout l'espace restant » (fr = fraction de l'espace libre). Pour les cartes, repeat(auto-fill, minmax(220px, 1fr)) veut dire « autant de colonnes de 220px minimum que possible » : du responsive sans media query.

Rule of thumb: flex for a row of things, grid for a page structure or a gallery. And always space siblings with gap rather than margins.

Règle simple : flex pour une rangée d'éléments, grid pour une structure de page ou une galerie. Et espace toujours les éléments voisins avec gap plutôt qu'avec des marges.

Debug trickAstuce de débogage

Lost in your layout? Temporarily add * { outline: 1px solid red; } at the end of the file: every box gets a red outline. In DevTools, the grid and flex badges next to an element draw its lines on the page.

Perdu dans ta mise en page ? Ajoute temporairement * { outline: 1px solid red; } à la fin du fichier : chaque boîte reçoit un contour rouge. Dans les DevTools, les badges grid et flex à côté d'un élément dessinent ses lignes sur la page.

A card is a componentUne carte est un composant

A component is a piece of HTML + CSS you repeat with different data. Design one card perfectly; the next step will stamp out 78 of them with JavaScript. Four CSS ideas make this card work:

Un composant est un morceau de HTML + CSS que l'on répète avec des données différentes. Conçois une carte parfaite ; l'étape suivante en fabriquera 78 avec JavaScript. Quatre idées CSS font fonctionner cette carte :

  • position: relative on the photo box + position: absolute on the year: the year is placed relative to the photo's corners (left: 14px; bottom: 6px).
  • position: relative sur la boîte photo + position: absolute sur l'année : l'année se place par rapport aux coins de la photo (left: 14px; bottom: 6px).
  • aspect-ratio: 4 / 5 + object-fit: cover: every photo gets the same shape, cropped neatly, whatever its original size.
  • aspect-ratio: 4 / 5 + object-fit: cover : toutes les photos ont la même forme, recadrées proprement, quelle que soit leur taille d'origine.
  • ::after creates a fake element used for the dark gradient that keeps the year readable on bright photos.
  • ::after crée un faux élément, utilisé pour le dégradé sombre qui garde l'année lisible sur les photos claires.
  • transition + :hover + transform: translateY(-6px): smooth lift on hover.
  • transition + :hover + transform: translateY(-6px) : la carte se soulève en douceur au survol.
